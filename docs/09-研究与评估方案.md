## 1. 研究定位

**问题：** 愿景里那五个研究问题，目前都还是一句话。评审无法判断它们是「真问题」还是「漂亮话」，工程也无法据此排期。本文的任务是把每一个研究问题拆到「能被证伪」的粒度：假设是什么、变量怎么操作化、数据从哪来、用什么方法、什么结果算支持、什么结果算推翻。

**一句话结论：** 这五个问题里，只有 RQ2（如何区分短期兴趣、长期兴趣、能力倾向与真实学习意愿）是真正硬的科学问题，其余四个更接近工程可靠性问题与产品价值问题。把研究资源平均分给五个问题是错的，RQ2 应当拿到最多资源。

### 1.1 一个前置判断

「兴趣」在教育心理学里没有公认的金标准测量。这意味着我们**不可能**做出一台「测出你真正兴趣」的仪器。我们能做的只有两件事：一是用多种不完美信号做三角验证，让结论的误差方向可预期；二是把结论表述成可纠正的假设而不是判定。这个前提决定了下面所有设计都必须包含「证据不足」这一合法输出。

> **取舍：** 我们放弃了「一次问卷定终身」的判定式方案（成本低、可规模化、但没有时间维度），选择「纵向交互 + 行为探针」方案（成本高、样本小、周期长）。原因：短问卷测到的几乎必然是短期兴趣与社会赞许性偏差，而项目的核心主张恰恰是「长期交互能识别问卷测不到的东西」——如果用问卷做核心方法，等于自己否证了自己的前提。

## 3. RQ1：长期交互与个人理解

**研究问题：** 相比一次性问卷，跨时间的多轮交互能否产出「问卷难以识别」的个人理解？

### 3.1 假设

- **H1a**：画像中至少一部分条目来自用户从未在结构化问卷中报告的内容（信息增量存在）。
- **H1b**：交互轮次与时间跨度增加时，画像条目的跨时间复现率上升（稳定性随交互增长）。
- **H1c**：信息增量主要集中在「过程性偏好」（如何学习、在什么条件下投入）而非「内容性偏好」（喜欢什么学科）。

### 3.2 操作化定义：什么叫「问卷难以识别的持续兴趣」

这是本节的关键。定义必须可测量，否则 H1a 无法证伪。我们采用四个可观测指标：

| 指标 | 定义 | 测量方式 |
| --- | --- | --- |
| 跨时间复现 | 同一主题在间隔 ≥ 14 天的 ≥ 2 个独立场景中被自发提及 | 会话编码，双人标注 |
| 自发引入 | 由考生主动提出，而非被系统追问后回答 | 编码时区分「主动 / 应答」 |
| 语境稳定 | 在「学习」「娱乐」「未来规划」三类语境下均出现 | 语境标签统计 |
| 行为印证 | 存在对应的探索行为记录（阅读、追问、完成任务） | 行为日志 |

「持续兴趣」判定为：跨时间复现 ∧ 自发引入，且至少满足语境稳定或行为印证之一。四项全不满足的，只能记为「一次提及」，不得进入画像 `[设计]`。

### 3.3 变量与数据

- 自变量：交互轮次、时间跨度、交互场景多样性。
- 因变量：信息增量率 = 画像条目中「基线问卷未覆盖」的比例；条目复现率。
- 控制变量：年级、选科组合、基线问卷得分。
- 数据来源：会话日志（依文档 08 授权）、基线问卷、探索行为日志、访谈。
- 基线对照：使用成熟的兴趣量表作为**对照基线**而非真值。量表分数只用于回答「这件事问卷能不能测到」，不用于判定用户「真正喜欢什么」——这一点必须写进研究报告，否则会被误读。

### 3.4 方法与判定标准

纵向单组设计，同一批考生在 T0（基线问卷）、T1（第 2 周）、T2（第 4 周）、T3（第 12 周）四个时间点采集。判定标准（目标值均为 `[假设]`，需在 MVP 后校准）：

- 信息增量率 ≥ 25%，且增量条目中「用户标记为『我自己没意识到但认同』」占比 ≥ 40%。
- 第 4 周与第 12 周的条目复现率 ≥ 60%。
- 若信息增量率 < 10%，则 H1a 不成立，产品主张需退回「问卷 + 解释」的形态。

### 3.5 伦理

基线问卷与画像结果都可能让考生产生「被定义」的不适。研究流程中必须有一次「你可以不同意任何一条结论」的显式环节，且该环节本身作为研究数据记录（不同意率是重要指标，不是失败）。

## 4. RQ2：兴趣状态的区分（本项目的核心难题）

**研究问题：** 能否把「短期兴趣、长期兴趣、能力倾向、真实学习意愿」四种状态区分开，而不是笼统地说「你对 X 感兴趣」？

### 4.1 为什么这是最硬的科学问题

四种状态在自陈层面几乎无法区分：一个刚看完科普视频的学生和一个已经自学两年的学生，都会说「我对生物感兴趣」。它们的差别不在「喜欢」的强度，而在**时间持续性、成本耐受度、相对表现**三个维度上。任何只问「有多喜欢」的测量都注定失败。

### 4.2 四构念的操作化定义

四构念的划分与定义目前处于 `[研究]` 状态：它综合了文献与访谈观察，尚未经本项目实证校准，标签名称、判别阈值与探针形式都可能随研究结果调整。

| 构念 | 定义 | 判别性特征 | 典型误判 |
| --- | --- | --- | --- |
| 短期兴趣 | 由具体情境激发，衰减快 | 7 天内高频提及，14 天后自发提及率骤降 | 被误判为长期兴趣 |
| 长期兴趣 | 跨情境、跨时间自发复现 | ≥ 3 个时间点、≥ 2 类语境复现 | 被误判为能力倾向 |
| 能力倾向 | 同类任务表现相对优于同伴，且学习速度快 | 微任务表现位于同批前 25%，第二次同类任务提升明显 | 被误判为兴趣（擅长≠喜欢） |
| 真实学习意愿 | 愿意为枯燥但必要的内容支付成本 | 在「无趣任务」上的坚持时长与完成后的追问 | 被误判为短期兴趣（因为一开始都兴奋） |

### 4.3 三类信号与四个探针

信号分三类：**自陈信号**（说了什么）、**行为信号**（做了什么）、**探针信号**（我们在受控条件下主动测什么）。前两类容易获得但容易被污染，探针信号成本高但判别力强。设计如下 `[设计中]`：

| 探针 | 设计 | 测什么 | 判读规则 |
| --- | --- | --- | --- |
| P1 微课与追问 | 15 分钟专业导论微课 + 3 题自评，完成后观察是否主动追问 | 学习意愿、兴趣深度 | 完成且追问 ≥ 1 个具体问题 → 意愿信号 + |
| P2 枯燥耐受 | 给一段真实培养方案中的硬核课程描述 + 3 道基础题，测是否继续 | 真实学习意愿 | 坚持 ≥ 20 分钟且完成 → 意愿信号 ++ |
| P3 时间贴现 | 二选一：立刻看 10 分钟趣味内容，或花 20 分钟练习换取更准的匹配 | 成本支付意愿 | 选后者 → 意愿信号 + |
| P4 两周回访 | 两周后不提示，观察是否主动提起该主题 | 跨时间持续性 | 主动提起 → 长期兴趣信号 + |

**关键设计原则：** 探针必须**伪装程度低、可解释**。我们不做隐藏计时、不做欺骗性实验，因为一旦考生发现被「测试」，测量本身就失效，且违反文档 08 的透明原则。P3 的时间贴现是明示的选择题，不是陷阱。

### 4.4 判别流程

```text
              +---------------------------+
              | 考生对主题 T 出现初始信号  |
              +------------+--------------+
                           |
                 [跨 >= 14 天是否自发复现?]
                    /                  \
                 否 /                    \ 是
                  v                      v
        +------------------+    +---------------------+
        | 短期兴趣         |    | 检查相对表现与成本  |
        | (需 2 周后复核)  |    +----------+----------+
        +------------------+               |
                              [P2/P3 是否愿意付成本?]
                                 /              \
                              否 /                \ 是
                               v                  v
                    +------------------+  +--------------------+
                    | 长期兴趣         |  | 检查能力倾向信号   |
                    | (偏好型)         |  +---------+----------+
                    +------------------+            |
                                        [表现是否位于前 25%?]
                                           /            \
                                        否 /              \ 是
                                         v                v
                              +------------------+  +------------------+
                              | 真实学习意愿     |  | 能力倾向 + 高意愿 |
                              | (意愿型)         |  | (最优先探索区)   |
                              +------------------+  +------------------+
```

四类之外必须保留第五个状态：**证据不足**。当信号冲突（例如跨时间复现但完全不愿付成本）时，输出「证据不足，建议再观察」而不是强行归类。强行归类是本设计最大的效度威胁。

### 4.5 判定标准

- **内部一致性**：四类标签与人工专家（2 名生涯规划从业者）盲评的一致率，Cohen's κ ≥ 0.6 `[假设]`。
- **预测效度**：T0 分类与 T3（3 个月后）的实际行为（是否选择了相关选科/专业方向、是否参加了相关活动）的一致率显著高于基线问卷。
- **若 κ < 0.4**：说明四类划分在操作层面不可靠，必须退回三分（长期兴趣 / 短期兴趣 / 不确定），这是设计上的降级路径。

### 4.6 效度威胁与对策

| 威胁 | 表现 | 对策 |
| --- | --- | --- |
| 社会赞许性 | 考生按「应该喜欢」回答 | 用行为与探针信号交叉，降低自陈权重 |
| 测量反身性 | 探针本身改变了兴趣 | 记录探针前后兴趣强度，把变化量作为分析对象而非噪声 |
| 霍桑效应 | 知道被研究而更投入 | 对照组不告知研究细节（需伦理审查批准） |
| 样本自选 | 愿意导入对话的人本身就更开放 | 报告中明确声明样本偏差，不外推总体 |

## 5. RQ3：画像到专业的可解释映射

**研究问题：** 从个人画像到专业建议的映射，是否既准确又可解释、并被考生认可？

采用三路评估，任何一路不过都算失败 `[设计]`：

| 路径 | 指标 | 方法 | 判定标准 |
| --- | --- | --- | --- |
| 用户认可 | 「这条推荐说得通」5 点量表 ≥ 4 的占比 | 逐条评分 + 追问理由 | ≥ 60% `[假设]` |
| 专家一致 | 与生涯规划师独立推荐的重合度 | 盲评、Cohen's κ | κ ≥ 0.5 `[假设]` |
| 可核查 | 推荐理由引用的培养方案字段是否真实存在 | 抽样回查知识图谱 | 编造率 = 0（一票否决） |

「可核查」这条是本项目的底线：**专业推荐的理由里出现的课程名、培养目标、选科要求，必须能在教育知识图谱里查到对应字段**。查不到即为幻觉，无论用户是否认可。

## 6. RQ4：Agent 决策可靠性

**研究问题：** 招生与志愿相关的 Agent 输出有多可靠？

### 6.1 指标定义（必须可复算）

| 指标 | 定义 | 测量 | 目标 |
| --- | --- | --- | --- |
| 无据陈述率 | 无证据支撑的事实性陈述 / 全部事实性陈述 | 抽样 ≥ 200 句，双人标注 | < 3% `[假设]` |
| 引用支持率 | 引用确实支持该句的比例 | 同上 | ≥ 95% `[假设]` |
| 规则校验覆盖率 | 确定性规则引擎判定的条款 / 该问题涉及的可判定条款 | 按规则清单逐项核对 | ≥ 90% `[假设]` |
| 越界率 | 出现「录取保证」「心理诊断」类表述的比例 | 关键词 + 人工复核 | 0（一票否决） |
| 拒答正确率 | 应拒答且拒答 / 应拒答总数 | 黄金集构造 | ≥ 85% `[假设]` |

### 6.2 方法

构建**黄金集**：由领域人员编写 100–200 条典型问题（专业是什么、选科能不能报、往年位次怎么用、这个专业学什么），每条给出参考答案要点与必须引用的数据源。标注采用双人独立 + 分歧仲裁，标注一致性 κ ≥ 0.7 才可使用该批数据。

**重要限制：** 黄金集的答案由人工依据公开资料编写，不是「标准答案」，只用于检验「是否编造」与「是否引对来源」，不用于检验「建议是否最优」。

## 7. RQ5：高校侧的个性化招生服务价值

**研究问题：** 高校招生办是否真的因为个性化专业探索服务而受益？

要度量的是**工作流效率**而不是录取效果 `[已确定]`：

- 重复性问题占比与答复工时变化（试点前后对比）。
- 内容缺口发现数：系统识别出的「考生高频问但知识库没有」的问题数量。
- 探索深度：考生在专业页面的停留与追问轮次（作为「了解得更深」的代理指标）。
- 招生办主观评价：结构化访谈，问具体场景而非满意度打分。

**明确不做：** 不度量录取人数、录取分数、报到率的变化，也不把这些作为价值证据（见 §9）。

---

## 8. 伦理审查

所有涉及考生的研究在启动前须通过伦理审查，包含以下要素 `[已确定]`：

1. **知情同意**：研究目的、数据处理方式、留存期限、退出方式，用高中生能读懂的语言写。
2. **最小风险**：不进行任何可能引发自我否定的评价反馈；不做心理诊断类结论。
3. **退出机制**：任何时间点可退出，退出后数据按文档 08 的删除流程处理，且不影响其使用产品。
4. **负面结果处理**：当研究结论对用户不利（如「该方向证据不足」）时，必须以「探索建议」而非「能力判定」的口吻反馈，并附替代方向。
5. **数据二次使用**：研究数据不用于产品训练；如需二次分析须重新告知。
6. **发表**：对外发表一律去标识化，且不发表可反查到个体的个案叙述。

## 9. 本研究明确不做的事

| 不做 | 原因 |
| --- | --- |
| 录取结果的因果推断（「用了万径所以录取更好」） | 存在强烈选择偏差与混杂，观测数据无法识别因果；任何此类结论都是误导 |
| 心理诊断、人格障碍判定 | 超出能力边界，且违反文档 08 与文档 14 的红线 |
| 高校之间的比较性评价 | 涉及声誉风险，且缺乏公允口径 |
| 长期（> 1 年）效果承诺 | 研究周期不支持，且考生决策窗口本身很短 |
| 未取得监护人同意的未成年人研究 | 合规前置条件，不可绕过 |
| 大样本横断面问卷研究作为主证据 | 只能测短期态度，与本项目主张不匹配 |

## 10. 研究节奏与依赖

时间盒与样本规模均为 `[假设]`，需在资源确认后校准：

- RQ1 / RQ2 依赖 MVP 的对话导入与画像能力，最早可在 Phase 1 后半段启动，建议周期 12 周（含 3 个月追踪）。
- RQ3 / RQ4 依赖知识图谱与规则引擎，最早 Phase 2。
- RQ5 依赖试点场景接入，最早 Phase 3。

验证方式：在 Phase 1 启动前与导师及伦理审查方确认周期是否可行；若不可行，RQ1/RQ2 的追踪期先压缩到 6 周并声明局限。
