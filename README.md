# 万径 WANJING

**Agentic Platform for Personalized Education Discovery & Decision Intelligence**

万径纵横，智见未来。

> 先认识自己，再探索专业，最后选择大学。

---

## 这是什么

万径是一个基于 AI Agent 的**个性化教育探索与智能决策平台**，面向高考志愿填报场景。

它试图重新表述一个问题：

> 在 AI 时代，大学志愿填报是否应该从「根据分数选择大学」，转变为「理解一个人，帮助他发现适合自己的教育与成长路径」？

传统志愿填报平台把这件事当成一个约束满足问题——给定分数、省份、选科，输出一个录取概率最优的序列。它优化的是"不浪费分数"。万径想优化的是"不浪费四年"。

对于一个即将进入大学、却可能尚未真正认识自己的高中生而言，院校信息、专业目录和历年分数线并不能直接回答最重要的问题：

- 我真正感兴趣的是什么？
- 我想研究什么问题、解决什么问题？
- 不同专业意味着怎样的学习经历与未来发展？
- 哪种大学教育路径更符合我的兴趣、能力与人生期待？

万径希望通过长期交互理解、人生设计方法论、多智能体协作和可信教育数据，帮助考生完成从自我认识到专业探索，再到大学选择的完整决策过程。

## 三条基本原则

| 原则 | 含义 | 落到工程上 |
| --- | --- | --- |
| **Understand the Person** | 理解一个人，而不仅仅是分析他的成绩 | 画像的每条判断挂证据、时间、置信度，用户可查看/纠正/删除 |
| **Explore the Possibilities** | 帮助探索多种路径，而不是过早给出单一答案 | 输出多条候选路径与可执行的验证任务，不输出"最适合你的专业 Top 3" |
| **Make Informed Decisions** | 用可靠数据和可解释机制支撑选择 | LLM 负责理解与解释，确定性程序负责规则校验与数据计算 |

## 两个产品方向

```text
                    万径 WANJING
                        │
        ┌───────────────┴───────────────┐
        │                               │
   考生端（C）                      高校端（B）
   Personal Education Discovery     University Intelligence
        │                               │
   先认识自己 → 再探索专业 → 最后选大学   招生知识库 + 招生 Agent
        │                               │
        └───────────────┬───────────────┘
                        │
        共享：教育知识图谱 + 决策引擎 + 数据治理
```

### 考生端 Personal Education Discovery

**1. 长期交互理解** —— 在用户明确授权的前提下，导入 ChatGPT、Claude、DeepSeek 等 AI 平台的历史对话，结合日记、学习记录与主动访谈，建立动态的个人认知画像：持续关注的知识领域、主动提出的问题及其复杂程度、长期兴趣与探索行为、学习偏好与认知倾向、个人价值观与职业期待。

**2. AI 人生设计与自我探索** —— 借鉴 Stanford Designing Your Life 等人生设计方法论，通过教练式对话帮助考生认识自己：苏格拉底式深度访谈、Workview / Lifeview、Good Time Journal、Odyssey Plans、兴趣假设验证与现实探索任务。系统不贴人格标签，而是提出可验证的假设。

**3. AI 专业发现与探索** —— 把个人画像与大学学科、专业知识体系建立可解释的关联：发现潜在学科方向、分析课程体系与培养目标、对比相近专业差异、解释所需能力与学习投入、输出多条探索路径而非单一推荐。

**4. 智能志愿决策** —— 在完成自我探索后进入实际决策：历年录取数据与位次分析、当年招生计划及选科要求、院校与专业组筛选、录取风险评估、冲稳保方案生成、多目标约束优化、招生章程与特殊录取条件校验。

### 高校端 University Intelligence

把高校分散的招生与培养信息组织成**可信知识库**，通过**个性化招生 Agent** 与考生对话，实现从「东北大学有哪些专业」到「根据我的兴趣和未来目标，东北大学有哪些专业值得我深入了解」的转变。东北大学为试点场景，架构上支持多高校接入。

## 技术架构

```text
                 WANJING
       Personalized Education Intelligence
                         │
          ┌──────────────┴──────────────┐
    Student Platform             University Platform
          │                             │
    Personal Agent                Admission Agent
          │                             │
    ┌─────┼──────┐              ┌───────┼───────┐
  Memory Coach  Major        Knowledge  Major  Admission
          │      │            Retrieval  Agent  Agent
    └─────┼──────┘              └───────┼───────┘
          └─────────────┬───────────────┘

               Education Intelligence
                        │
          ┌─────────────┼───────────────┐
     Personal KG   Education KG    Decision Engine
          └─────────────┼───────────────┘
                        │
                 Trusted Data Layer
         Admissions / Majors / Curriculum / Universities
```

| 模块 | 主要职责 |
| --- | --- |
| Personal Memory | 长期交互记忆与个人画像 |
| Self Discovery | 人生设计与兴趣探索 |
| Major Discovery | 学科专业发现与匹配 |
| University Agent | 高校专业知识问答 |
| Admission Agent | 招生信息检索与咨询 |
| Decision Engine | 志愿推荐与多目标优化 |
| Knowledge Graph | 个人与教育知识图谱 |
| Data Governance | 数据采集、清洗、校验与溯源 |

**关键技术方向**：LLM & Agent Frameworks、Agent Skills & Tool Calling、RAG & Hybrid Retrieval、Long-term Memory、Knowledge Graph、Multi-objective Optimization、Structured Decision Making、Data Engineering。具体选型随 MVP 实验逐步确定。

## 原型说明

`prototype/miniprogram/` 是一个微信小程序原型，用最小成本验证「志愿决策台」的信息结构与匹配算法：

- `pages/index` —— 志愿方案主页面（分数/省份/选科输入、方案列表）
- `pages/report` —— 分析报告页
- `components/` —— 12 个组件：校群卡片、志愿卡片、历史位次表、风险带、满意度、AI 对话等
- `utils/` —— `matching.js`（录取匹配）、`major-map.js`（专业映射）、`province-config.js`（省份规则）、`api.js`

打开方式：用**微信开发者工具**导入 `prototype/miniprogram/` 目录。原型内的数据为演示用途，不构成任何录取判断依据。

## 核心研究问题

1. **长期交互与个人理解**：能否通过人与 AI 的长期交互记录，发现传统兴趣问卷难以识别的持续兴趣与学习动机？
2. **兴趣发现与验证**：如何区分短期兴趣、长期兴趣、能力倾向与真实学习意愿？
3. **个人画像与专业匹配**：如何建立可解释、可验证的个人特征与专业培养要求之间的映射？
4. **Agent 决策可靠性**：如何通过检索增强、确定性规则和多 Agent 审核，减少招生信息幻觉与错误推荐？
5. **个性化招生服务**：如何将高校专业知识转化为能够理解不同考生需求的智能交互服务？

每个问题的可验证设计见 [研究与评估方案](docs/09-研究与评估方案.md)。

## 设计哲学

我们相信，AI 不应该替一个年轻人决定他应该成为谁。

它应该帮助他认识自己的兴趣，理解世界的知识体系，探索不同的可能性，并拥有做出自主选择的能力。

对于大学而言，招生也不应该止于展示分数线、专业目录和招生简章。大学应该能够真正向每一位考生解释：我们在研究什么、培养什么样的人，以及这里的哪些知识和机会可能与你的未来产生联系。

万径，希望连接一个人的可能性与大学的知识世界。

## 我们不做什么

一份诚实的项目说明必须包含边界：

- 不做录取结果的保证或承诺
- 不做心理诊断与人格测评打分
- 不做"代填志愿"的一键托管
- 不做付费推荐位
- 不用考生画像做任何录取相关的自动决策
- 不在未授权情况下采集或推断用户信息

完整清单与理由见 [愿景文档 §7](docs/01-产品愿景与设计哲学.md)。
